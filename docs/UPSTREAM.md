# Upstream attribution

Memhub started from the open-source Memmy Agent codebase maintained by MemTensor:

- Upstream repository: `https://github.com/MemTensor/memmy-agent`
- Initial Memhub work was based on the upstream `v1.1.4` line.

Inherited source code, notices and license obligations remain attributable to the upstream project. Memhub-specific work adds or changes product boundaries, project/account isolation, privacy defaults, MCP gateway behavior, capture/Bridge transport and Local/Server deployment editions.
